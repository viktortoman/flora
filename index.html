A program lényege: A Raiffeisen lakossági ügyfelei hűségpontokért cserébe kedvezményeket kapnak partnereinktől.

Üzleti modell: A csatlakozás a partnereknek ingyenes. Cserébe egyedi (%-os vagy fix Ft) kedvezményt várunk el, amit kizárólag a program tagjai érhetnek el.

Amit nyújtunk: Reklámozzuk a partnereket a husegprogram.raiffeisen.hu oldalon, hírlevelekben és mobilalkalmazás push értesítésekben.
